# 2457. 美丽整数的最小增量

给你两个正整数 `n` 和 `target`。如果一个整数的各位数字之和不超过 `target`，就称它是**美丽**的。

返回使 `n + x` 成为美丽整数的最小非负整数 `x`。输入保证总能让 `n` 变得美丽。

**示例 1：**

```
输入：n = 16, target = 6
输出：4
解释：16 的数位和是 7；加 4 得到 20，数位和是 2。加 0 到 3 都不够。
```

**示例 2：**

```
输入：n = 467, target = 6
输出：33
解释：467 + 33 = 500，数位和是 5。
```

**示例 3：**

```
输入：n = 1, target = 1
输出：0
解释：1 本身已经是美丽的。
```

**提示：**

- `1 <= n <= 10^12`
- `1 <= target <= 150`
- 输入保证总能让 `n` 变得美丽
